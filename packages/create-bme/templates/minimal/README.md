# BME Minimal Example

Bare-bones Node.js setup to test memory extraction and recall.

## Setup

```bash
npm install
export API_KEY="sk-your-deepseek-key"
npm start
```

This will:
1. Create a demo persona
2. Run 3 conversation turns
3. Extract facts after every 2 messages
4. Display extracted memories

Perfect for testing or integrating into a larger app.
